# Чистон — рисованная версия 2

8 серий: `chiston-v2-ep1.mp4` … `chiston-v2-ep8.mp4`.
Новые лица и одежда в стиле утверждённого рисунка, голоса Silero, губы в такт голосу, плавная камера.

## Исходники (`src/`)
- `lib.js`, `lib2.js` — рисунки сцен и героев из первой версии.
- `style2.js` — новый стиль: головы, лица, причёски, тела и одежда, синхронизация губ, камера.
- `ep1.js` … `ep8.js` — сцены и реплики серий.
- `engine.js` / `engine2.js` — плеер и таймлайн.
- `cuesN_orig.json` — реплики, `warpN.json` — подгонка сцен под длину фраз, `envN.json` — громкость голоса для губ.
- `build2.py N` собирает страницу серии, `build2d.sh N` — полный цикл: голоса → кадры → музыка → видео.
