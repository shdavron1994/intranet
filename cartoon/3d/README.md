3D-версия сериала для Дилшода и Томирис: камера движется, сцены объёмные, голоса естественные (Silero TTS, офлайн, без ключей).

## Как устроено (`src/`)

- `world.js`, `person.js`, `cast.js` — рендер Three.js, персонажи и семья.
- `sets.js`, `sets2.js` — декорации: спальня, ванная, кухня с чайником-Чистоном, гостиная, двор, улица, парк «Лимпопо».
- `kit.js` — общая сцена для серий 2–8 (свет, смена декораций, позы «сидит», «идёт», «ест»).
- `eng3d.js` — таймлайн, субтитры, растягивание сцен под длину фраз.
- `epN_3d.js` — сцены серии N; `explain2d.js` — рисованные вставки (горло, передача про животных, сахар).
- `build_ep.sh N PORT` — полный цикл: реплики → голоса Silero (`make_silero.py`) → `warp3d.py` → рендер кадров (`export3d.js`, Chromium + SwiftShader) → музыка (`../series/src/audio.js`) → сведение (`mix3d.py`).

Фотографии семьи использовались только как образец внешности и в репозиторий не добавлены.
